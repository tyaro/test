# 🏡 箱庭双六 — Babylon.js プロトタイプ

Babylon.js と Cannon.js を使用した、ブラウザで動作する **3D 双六（すごろく）ゲーム**のプロトタイプです。
箱庭風の3Dシーンの中にボードゲームのマス目を配置し、サイコロを振ってキャラクターを進めることができます。

---

## 🎮 機能

| 機能 | 説明 |
|------|------|
| **3D 箱庭シーン** | 草地の地形に木々や石を装飾した箱庭型マップ |
| **ArcRotateCamera** | マウスドラッグ・ホイールで自由にカメラを操作可能 |
| **物理サイコロ** | Cannon.js 物理エンジンで転がる3Dサイコロ |
| **蛇行マス目（双六）** | 20マスの蛇行パターン（スネーク形式）のボード |
| **キャラクター移動** | 出目に応じて放物線アーチアニメーションでマス移動 |
| **特殊マス** | ボーナス（進む）・ペナルティ（戻る）・ゴールマス |
| **HTML UI** | サイコロボタン・結果表示・マス凡例・カメラ操作ヒント |

## 🚀 起動方法

### 必要環境

- Node.js 18 以上
- npm

### セットアップ

```bash
# リポジトリをクローン
git clone https://github.com/tyaro/test.git
cd test

# 依存関係のインストール（任意）
npm install

# ローカルサーバーを起動
npm start
```

起動後、ブラウザで **`http://localhost:3000/public/index.html`** を開いてください。

> **注意**: `index.html` を直接ファイルとして開くと、スクリプトのパス解決に失敗する場合があります。
> 必ず `npm start`（`npx serve .`）などのローカルサーバー経由でアクセスしてください。

## 📦 使用技術

| 技術 | バージョン | 用途 |
|------|-----------|------|
| [Babylon.js](https://www.babylonjs.com/) | 7.x (CDN) | 3Dレンダリング・シーン管理 |
| [Cannon.js](https://github.com/schteppe/cannon.js) | 0.6.x (CDN) | 3D物理エンジン（サイコロの転がり） |
| HTML / CSS / JavaScript | — | UI・ゲームロジック |

> **依存関係はCDNで配信**されるため、`npm install` なしでもブラウザから直接実行できます。
> `package.json` は将来的なバンドル化・拡張に向けた依存関係の記録として使用しています。

## 🎲 遊び方

1. ブラウザでゲームを開く
2. **「🎲 サイコロを振る」** ボタンをクリック
3. 出目の数だけキャラクター（赤い球）がマス目を進む
4. 特殊マスに止まると追加効果が発動：
   - 🟡 **ボーナスマス**（5番・15番）: 追加で進む
   - 🔴 **ペナルティマス**（10番）: 後退する
   - 🟠 **ゴールマス**（19番）: クリア！
5. ゴールに到達したら「もう一度遊ぶ」でリセット
